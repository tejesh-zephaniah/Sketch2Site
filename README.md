Sketch2Site is an AI-powered web application that converts hand-drawn website sketches and wireframes into functional HTML and CSS code.

Simply upload your drawing (or multiple reference images), and the application analyzes the design to generate a website layout inspired by your sketches.

## ✨ Features
- 📸 Upload multiple sketch/reference images.
- 🤖 AI-powered sketch-to-website generation.
- 🎨 Converts visual layouts into HTML and CSS.
- 💻 Generates website designs based on uploaded references.
- ⚡ Fast and simple workflow.

## 🛠️ Tech Stack
- **Frontend:** React, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **AI:** Image-based design analysis and code generation

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone <your-repository-url>
cd hack_da_decipher
```

### 2. Install dependencies

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

**Backend (in a separate terminal):**
```bash
cd backend
npm install
npm run dev
```

### Deploy to Render

1. Push this repository to GitHub.
2. In Render, choose **New > Blueprint** and connect this repository. Render will read `render.yaml` and create the frontend and backend services.
3. Enter your `GEMINI_API_KEY` when prompted for the backend service. Do not commit the key to the repository.
4. Wait for both services to finish deploying, then open the frontend service URL.

The frontend and backend URLs are linked by the Blueprint. The free backend service may take a little time to wake up after inactivity.
