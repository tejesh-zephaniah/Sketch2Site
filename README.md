Sketch2Site is an AI-powered web application that converts hand-drawn website sketches and wireframes into functional HTML and CSS code.

Simply upload your drawing (or multiple reference images), and the application analyzes the design to generate a website layout inspired by your sketches.

## ✨ Features
- 📸 Upload multiple sketch/reference images.
- 🤖 AI-powered sketch-to-website generation.
- 🎨 Converts visual layouts into HTML and CSS.
- 💻 Generates website designs based on uploaded references.
- ⚡ Fast and simple workflow.

## 🛠️ Tech Stack
- **Frontend:** React, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **AI:** Image-based design analysis and code generation

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone <your-repository-url>
cd hack_da_decipher
```

### 2. Install dependencies

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

**Backend (in a separate terminal):**
```bash
cd backend
npm install
npm run dev
```

## 🎯 Goal

To bridge the gap between imagination and implementation by transforming hand-drawn website ideas into code, making web development faster, easier, and more accessible.
